* Package Requirements

The project has been run successfully with the below listed packages and their corresponding versions.

- python 3.13.0 :: Since python 3.12 many typing features and pattern matching has been introduced which are heavily used in this project.
- tensorflow 2.21.0 :: low level API for working with neural networks
- keras 3.13.2 :: high level API for working with neural networks
- msgspec 0.21.1 :: serialization library for persisting configurations
- scikit-learn 1.8.0 :: library that provides many machine learning utilities
- matplotlib 3.10.8 :: library for visualization e.g. for creating plot and histograms
- numpy 2.4.3 :: library that provides an interface for many math operations e.g. working with matrices
- scipy 1.17.1 :: library that provides many mathematical high level utilities e.g. useful for signal processing tasks
